# v0.4.0：照片展示与悬浮关闭速度

照片默认按原图比例展示，长图在卡片内滚动查看。每张图片的“调整图片”入口提供三种显示方式：原图比例、指定高度内完整显示、铺满裁切。支持 50%–300% 缩放、上下/左右焦点、指针拖动和 100–480 px 的窗口高度；可一键恢复原图。

设置作为可选的 `media.imageLayout` 保存在项目中，旧项目无需迁移。编辑器和导出阅读器共用 `imagePresentation` 生成展示样式，原始照片字节不变。设置支持本地保存、撤销、项目 ZIP 导入导出，并用于三个卡片模板、阅读预览、HTML 和离线 ZIP。

鼠标离开热点、卡片及安全通道后，从 250 ms 改为等待 150 ms 关闭，进入延迟仍为 180 ms。离线阅读页的持续鼠标移动不会反复重启关闭计时；重新移入卡片会取消关闭。

已验证：

- 类型检查、普通生产构建通过；43 项单元测试通过，包括旧媒体兼容、设置序列化及非法数值拒绝。
- 5 项相关浏览器测试通过：照片上传/调整/拖动/刷新/撤销/导出/恢复、离线关闭/重入，以及既有安全通道、轮播和图片排序/替换流程。
- 另两项阅读器/视频回归及一项作者/快照集成测试通过；这些为不同的测试运行，不合并称作一次完整套件。
- Vercel 使用的免登录网页构建通过；在该生产构建上另行运行照片完整流程和朋友上传/标注/三种导出/恢复流程，两项均通过。
- 390 px 手机视口中，照片调整弹窗不超出屏幕，缩放和“完成”操作可用，无脚本异常。此项为模拟视口，未测试实体微信。
