## 已有验证与外部条件

- 单元测试 28 项通过，类型检查和生产构建通过。
- 此前完整浏览器流程 8 项通过，含作者隔离、匿名阅读和撤回；新增相同 PDF 回归后，无云配置的本地编辑流程 8 项通过。两次测试范围不同，不应相加作为一次完整套件的结果。
- 本机启动包在全新解压目录完成自动安装、启动、上传/框选/编辑、刷新恢复和 HTML 导出。Windows/macOS 双击入口未在对应实体系统上实测。
- 当前可用工作流为 PDF 本地编辑/导出，以及 PostgreSQL + 私有本地目录的作者和发布流程；AI、MinIO、正式 HTTPS、邮件服务、微信真机和新云任务恢复仍有限制。
- 本 PRD 以“全部 P0 验收通过”定义完整 MVP；当前交付属于可用首版，不应称为全部 PRD 验收完成。
