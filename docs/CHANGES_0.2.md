# v0.2.0：清晰度与本机编辑体验

根据用户试用反馈修复四项问题：

1. 编辑区最低 2 倍像素密度渲染，跟随高分屏设备像素比，缩放时重新绘制。阅读预览、分享快照和离线导出的页面统一改为 3 倍分辨率无损 PNG。超大页面以 1600 万像素及单边 8192 像素为预算上限。旧项目在编辑器中打开后自动重新生成页面，原始 PDF 字节不变。
2. 新增可见的撤销、重做、删除工具条，以及左侧逐条删除入口。历史记录保留最多 50 步，同字段连续输入在 800ms 内合并；删除可撤销，撤销后新操作会清空重做。切换项目或刷新会清空历史，不影响已保存的项目内容。输入框保留系统原生快捷键。
3. 去除文字热点的底色、下划线与选中阴影。通过 PDF.js 原有字形重新绘制文字着色，并保留裁剪区域内的原始纸张与图像；没有用浏览器字体覆盖原文。新增 12 款柔和配色、自定义颜色和基于原始页面色彩的推荐色。按用户最新要求，文字标注样式优先于 PRD 初始样式。
4. 顶部新增明显的“上传 PDF”主按钮，左侧上传入口改为大号实色按钮。

Windows 自动更新器下载并准备新目录后再替换服务，保留旧目录；固定使用 `http://localhost:3000` 以延续同一浏览器的 IndexedDB 项目。创建“HoverCV 更新并启动”桌面快捷方式，后续可双击更新。只结束能够从命令行识别出的 HoverCV/Next Node 进程树；其他端口占用会报错并保留原进程。版本通过 `package.json` 检查，维护者发版须同时更新 `package.json`、锁文件根版本及 `lib/version.ts`。

验证范围：

- 浏览器像素对比验证着色后的字符发生变化，浅色纸张像素保持原样；透明热点没有下划线、底色或阴影。
- 实际鼠标创建、撤销、重做、删除后恢复说明、刷新恢复；验证文本框 Backspace 不会删除注释。
- DPR 1 / 3 的 Canvas 像素密度、200% 重新渲染、高清 PNG 尺寸，以及导出 ZIP 中 PDF 与输入逐字节一致。
- 用户提供的两页私人简历项目在独立浏览器上下文导入，3 条标注保留，页面升级为 PNG，无浏览器异常。私人文件与截图始终在仓库外。
- Windows 更新脚本使用官方校验过的 PowerShell 运行时做语法检查，并模拟首次下载、重复启动、进程树替换、其他程序占用保护、生成批处理命令引号。未在实体 Windows 上运行 CIM、桌面快捷方式和进程终止操作。

生产构建、类型检查与单元测试通过；浏览器测试覆盖范围见验收记录。AI、MinIO、公网部署和微信真机的既有限制未因本次修复而消失。
