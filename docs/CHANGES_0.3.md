# v0.3.0：更高的编辑区与自由调整的布局

用户反馈的蓝线区域上移、红线边界可调整，落实为：

- 项目标题区从多行改为 50px 的紧凑单行，画布提示由 49px 改为 28px。1600×1000 测试窗口中，画布从 y=163px 开始，PDF 从 y=191px 开始，比 v0.2.0 同尺寸截图上移约 100px。
- 左右两侧使用 10px 分隔条，可真实鼠标拖动、点击箭头折叠和展开、双击复位，也可通过方向键、Home/End 操作。左栏 180–360px，右栏 240–520px，按当前窗口和另一侧宽度限制，保留至少 360px 桌面编辑区。屏幕变小时隐藏对应侧栏或切换注释浮层，不覆盖原先保存的桌面宽度偏好。
- 面板宽度与折叠状态保存在 localStorage，刷新后恢复；与简历项目、编辑撤销、导出内容及 PDF 坐标独立。新建或编辑注释会自动展开被收起的注释面板。
- 新增“拖动”工具、按住空格临时拖动、鼠标中键拖动；使用指针捕获结束拖动，避免误选文字或生成注释。输入框仍接收空格等原生按键。
- Ctrl/⌘+滚轮在画布内控制 40%–200% 缩放，记录鼠标指向的 PDF 页面相对坐标，页面更新尺寸后恢复位置。普通滚轮仍滚动；加减按钮和适合宽度保留。滚动到边界时，锚点恢复受浏览器滚动范围限制。

实际浏览器回归覆盖：双侧拖动、折叠、宽度记忆和重置；键盘操作；390px 与 900px 响应式切换；三种平移；不误建注释；正文空格输入；Ctrl 滚轮指向稳定；普通滚动；调整边界后的注释归一化坐标一致。

Windows 自动更新入口保持原路径，通过版本号检测获取 v0.3.0。无需手动打开 GitHub 下载；同一浏览器和 localhost:3000 的原有项目可继续使用。Windows 桌面进程替换与快捷方式沿用此前已模拟检查的脚本，本次未在实体 Windows 操作。
