# HoverCV 交互简历注释工具产品需求文档

版本：1.0　日期：2026年10月17日　状态：开发基线　产品名：暂定 HoverCV

本文面向产品负责人、设计者与 Codex 开发者，定义一个可供多人使用、可自行部署并准备开源的网页应用。用户上传 PDF 后，在文字或图片区域添加可交互的悬浮卡片；HR 通过公开阅读链接查看，电脑悬停、手机点击，无需 OpenAI 账户。首版应完成上传、标记、编辑、AI 辅助、预览、保存、分享与导出的完整流程。

交互由网页实现。原 PDF 作为版面底稿和可选下载附件；PDF 附件本身不作为统一悬停体验的承载格式。以下尺寸、容量和延迟是首版建议默认值，可配置；性能数值是待测试的验收目标。

## 1 产品目标与边界

### 1.1 要解决的问题

简历正文空间有限，求职者希望把公司背景、技术解释、项目成果、照片和视频放到相关文字旁边。阅读者按需展开内容，鼠标离开后卡片消失，正文不被挤动，也不需要先进入另一套账户体系。

第一使用场景是：用户在简历中选中 WaytoAGI，添加社区简介与三张图片；HR 悬停时，旁边出现统一尺寸的小框，能继续移入框内切图和点击，移开后自动关闭。

### 1.2 角色与权限

| 角色 | 能做什么 | 登录要求 |
| --- | --- | --- |
| 本地体验用户 | 上传并在本机编辑、预览、导入导出项目 | 无需登录；默认不上传 PDF 到云端 |
| 简历作者 | 云端保存、AI 搜索、发布、更新和撤回自己的简历 | 使用产品自己的账户体系 |
| HR 或其他阅读者 | 查看已发布内容、展开卡片、使用媒体控件 | 阅读链接免登录，不跳转 OpenAI 登录 |
| 部署维护者 | 配置存储、AI、搜索、配额与服务参数 | 使用部署配置和管理权限 |

### 1.3 首版必须交付

首版包括七项用户需求、云端发布和可移植导出。开发按阶段推进，但只有最后一阶段通过全部 P0 验收，才可称为 MVP 完成。缺少 AI 密钥时，手工编辑继续可用，真实 AI 功能显示未配置；不能把模拟结果称为搜索完成。

P1：扫描件 OCR、自动吸附 PDF 中的独立图片、多人协作、自定义域名、阅读统计、批量自动注释。首版扫描件仍可框选区域并手工录入关键词。暂不做任意网页嵌入、任意 HTML 执行、改写原 PDF 排版或承诺原生 PDF 悬停兼容。

## 2 七项需求与功能对应

| 用户需求 | 首版实现 | 关键验收 |
| --- | --- | --- |
| 上传简历 PDF 后添加注释 | PDF 渲染、文字层、热点层、项目保存 | 上传真实 PDF 后即可开始编辑 |
| 选中文字或图片作为链接点 | 文字选择与矩形框选两种工具 | 多行文字保存多个矩形；图片可手工框选 |
| AI 搜索并给出准确简要注释 | 联网搜索、基于来源生成、人工确认 | 展示来源和不确定性，无凭空编造 |
| 放入照片、视频、文本和链接 | 内容块编辑、拖入上传、排序、媒体控件 | 保存、重开、分享后素材仍可用 |
| 统一尺寸及固定模板 | 三个模板、统一框架、可选背景图 | 内容超出时内部滚动，不撑大外框 |
| 悬停进入和离开体验 | 延迟、过渡安全区、自动关闭、边界避让 | 移入框内不闪退，离开后关闭 |
| 特殊颜色标记 | 主题色候选、固定色板、手动选色 | 各种缩放下标记仍准确且清晰 |

## 3 页面与主要流程

### 3.1 页面结构

首页提供上传入口、无真实个人信息的示例和功能说明。编辑器采用左侧页码与工具、中间 PDF、右侧注释编辑面板的布局。顶部显示编辑或预览模式、保存状态、主题、发布和导出操作。窄屏将编辑面板改为抽屉。

阅读页只保留简历、必要的缩放及页码控件和热点说明，不显示编辑按钮、AI 输入框或作者后台。项目列表用于继续编辑、复制、重命名、撤回和删除。

### 3.2 作者流程

上传 PDF → 选择文字或框选图片 → 创建注释 → 手工添加内容或生成 AI 草稿 → 调整模板与颜色 → 预览交互 → 保存 → 发布免登录链接或导出文件。

本地项目在 IndexedDB 保存，关闭页面后可恢复。云端保存前要求作者登录，并明确显示哪些文件将上传。存储失败须显示原因和重试或导出入口，不能把失败状态显示为已保存。

### 3.3 HR 流程

打开公开链接 → 直接看到简历 → 发现彩色热点 → 电脑悬停或手机点击 → 查看卡片并操作媒体 → 离开卡片或主动关闭 → 继续阅读。

## 4 PDF 上传与锚点选择

### 4.1 文件与异常

默认上限：单个 PDF 20 MB、20 页，每项目 100 个注释；这些限制在配置中统一定义。校验扩展名、MIME、文件签名、大小和解析结果。损坏或不支持的文件显示可操作的错误。

密码 PDF 可在本机提示输入打开密码，密码不保存到项目或日志。不能打开或没有相应权限时停止处理，不尝试绕过保护。解析期间显示进度，允许取消；长文档按可见页懒加载，释放离屏 Canvas，避免一次渲染全部高清页面。

### 4.2 文字工具

使用 PDF.js 文字层支持真实选择。释放鼠标后出现“添加注释”入口；选区未确认前不能自动创建热点。相同词出现多次时，仅标记本次选中的那一处。

多行选区保存多个矩形并合并同一行相邻片段，不能用一个大矩形覆盖行间空白或另一栏。首版不支持一次选择跨页文字；提示分成两个注释。提取文字与画面不一致或不可选择时，提供框选模式和手动关键词。

### 4.3 图片与区域工具

进入框选模式后，拖拽覆盖 LOGO、照片、图标或扫描文字。区域可移动、调整大小、取消，保存前不能只留下一个空框。图片入口使用描边和小角标；框选本身不代表已经准确提取原 PDF 中的独立图片。

扫描文字和图片进行 AI 搜索前，用户填写关键词；不能把缺少 OCR 的区域当作已识别文字。

### 4.4 坐标与源文件绑定

锚点绑定 PDF 文件的 SHA-256 指纹和页码。持久化原生 PDF 坐标矩形，统一为 x0、y0、x1、y1，坐标转换交给 PageViewport 的正反变换，正确考虑 CropBox 偏移、页面旋转和原始坐标方向。[S1][S2]

浏览器选择框先转换为页面内 CSS 坐标，再转换为 PDF 坐标；Canvas 的 devicePixelRatio 只影响绘制清晰度，不能再次乘进热点位置。显示时按当前 viewport 转回 CSS 坐标，并规范化矩形左右上下边界。

记录 textQuote 及少量前后文，用于定位校验。更换 PDF 必须生成新文档版本；旧锚点标为需重新定位，不可默认沿用。保存后在 50%、100%、150%、200% 缩放，窗口变化、DPR 1/2 和 0/90/180/270 度旋转下验证，热点边界偏差目标不超过 2 CSS px。

## 5 内容编辑与 AI 辅助

### 5.1 注释内容

每个注释包括标题、内容块、模板、颜色、可选封面、来源和发布状态。支持文字、图片组、视频、链接四类内容块；可新增、排序、替换、删除和填写说明，不要求用户编写代码。

默认每卡片最多 20 个内容块、12 张图片、3 段视频；标题建议 30 字以内，正文最多 2000 字。图片支持 JPEG、PNG、WebP，单张 10 MB；视频首版支持 MP4 H.264/AAC，单段 100 MB；项目总资源默认 250 MB。上传显示进度、失败重试和最终状态。视频格式不能播放时给出转码提示，不把有文件扩展名等同于可播放。

链接保存标题和 HTTPS URL，使用新标签页打开。任意网页默认展示为链接卡片，不直接插入 iframe。用户上传的 SVG、HTML 和脚本文件不作为可执行内容接收。

### 5.2 图片和视频交互

图片组支持上一张、下一张、页码、键盘切换和可选自动播放。默认手动切换；开启后每 3.5 秒切换。鼠标或焦点停在媒体控件上时暂停自动播放，关闭卡片时停止计时，下次展开从第一张开始。图片默认 contain，支持统一的 cover 预览和裁切焦点设置。

视频不自动播放有声内容。离开并关闭卡片后立即暂停，不能在后台继续发声。进入原生全屏播放时暂缓自动关闭，退出全屏后恢复常规规则。视频和图片切换不改变卡片外框尺寸。

### 5.3 AI 搜索入口

作者在编辑面板或注释框的编辑状态中点击“AI 搜索介绍”。系统显示将发送的关键词，可附带作者确认的少量上下文。默认只发送所选关键词和最多 200 字上下文；完整 PDF、联系方式和其他页面不自动发送给搜索或模型服务。

流程为：确认关键词 → 调用真实搜索接口 → 整理来源 → 模型基于来源生成 → 展示草稿及引用 → 作者编辑并确认 → 写入注释。AI 不在 HR 每次悬停时重新运行，以免造成延迟和重复费用。

搜索默认返回 3 至 5 项，优先官网、官方文档与一手资料。中文简介建议 60 至 120 字，最多三个要点；每条实质性事实带来源 ID，可点击查看来源标题、URL 和检索时间。无充分证据时返回“未找到足够可靠资料”，允许手写和重试。不得根据机构介绍推断申请人的岗位、贡献、成交额或获奖情况。

生成内容使用结构化 JSON：title、summary、bullets、citations、uncertainty。引用 ID 必须来自实际搜索结果，服务端校验，不能让模型自行编出链接。网页与 PDF 内容都是资料，不能作为更改系统规则、读取密钥或执行操作的指令。

### 5.4 背景图与代表性图片

提供“搜索配图”入口，按关键词返回最多六张候选缩略图；作者选择后设置为卡片封面或模板背景。记录来源页、作者、许可说明和图片 URL；未提供许可信息时显示“许可信息未知，需自行确认”。搜索结果不能冒充作者本人工作照片。

首版只实现一种真实图片检索提供方，并通过接口隔离；优先采用能返回图片及来源的搜索服务。[S4] 没有搜索配置或结果时，可上传图片或使用内置纯色背景，不显示虚假的候选结果。确认导入的图片通过受控下载保存到自己的资源存储，避免公开阅读依赖不稳定的远程热链。

### 5.5 AI 与搜索的状态

状态包括未配置、待确认、搜索中、生成中、待采纳、完成和失败。30 秒超时可取消、重试；失败保留人工草稿。新结果不能覆盖尚未保存的人工修改。后端按作者和 IP 限流，配置日配额与成本上限；搜索、模型和图片服务均由部署者配置，默认不开放无限匿名调用。

## 6 卡片模板与悬浮规则

### 6.1 三个固定模板

| 模板 | 内容布局 | 适用场景 |
| --- | --- | --- |
| 简介模板 | 标题、简短说明、要点、来源或链接 | 机构、技术与名词解释 |
| 图文模板 | 标题、固定媒体区、说明、图片或视频控件 | 公司产品、工作记录、项目作品 |
| 封面模板 | 背景图、可读文字底层、标题、摘要、链接 | 活动或项目的视觉入口 |

电脑端三个模板共用 360 × 420 CSS px 外框，圆角 12 px、内边距 16 px、标题最多两行。媒体区高度 176 px；过长内容在卡片内部滚动，头部保留关闭入口。主题字体统一，不提供任意拖拽放大卡片。

视口不足时宽度为 min(360px, 视口宽度减24px)，高度不超过可见视口减24px。手机使用同一内容模板的底部浮层，最大高度 70dvh。背景图加固定文字底层和渐变遮罩，正文始终可读；背景加载失败使用主题纯色。

### 6.2 悬停状态机

状态为 Closed、Opening、Open、Closing。桌面指针进入热点后延迟 180 ms 展开；180 ms 内离开则取消。指针位于热点、卡片或连接二者的动态安全通道时保持打开；移出这些区域后延迟 250 ms 关闭，重入立即取消关闭。

热区到卡片通常留 8 px 间隙，使用安全通道判断穿越，而非只给文字绑定 mouseleave。建议采用 Floating UI 的 useHover 与 safePolygon，并结合定位的 offset、flip、shift、size 和 autoUpdate。[S3]

任意时刻仅打开一张卡片。移向另一热点时结束旧卡片媒体，切换到新卡片，不叠加旧计时器。卡片默认从触发位置右侧打开；空间不足翻到左侧，再在视口内避让。缩放、滚动和页面旋转后重新定位；触发点离开视口时关闭。

阅读状态不提供永久固定卡片；作者编辑使用独立编辑面板，不能因鼠标离开而丢失修改。卡片以覆盖层呈现，不插入正文、不移动原页面布局。

### 6.3 键盘与手机

热点能用 Tab 聚焦，焦点进入后展开；焦点仍在热点或卡片内时，鼠标离开不强制关闭。Esc 关闭并把焦点返回触发点，不能马上再次弹开。包含可点击控件的卡片使用非模态 dialog 语义，不使用只适合纯说明文字的 tooltip 语义。

手机没有悬停，用点击打开；点外部、关闭按钮或返回操作关闭。底部浮层管理焦点，正文仍允许原生缩放。全屏视频退出后恢复阅读位置。

## 7 标记颜色与视觉要求

默认提供蓝、绿、紫、琥珀四色及自定义颜色；例如蓝色 #295CAA。用户可在设置中选择“沿用简历主色”，系统从前几页渲染结果给出候选色，过滤接近黑、白、灰的像素，再由用户确认，避免自动把人像肤色当主题色。

文字使用同色下划线与低透明度高亮，图片使用描边和角标。首版不直接重写源 PDF 字体或覆盖重画文字，以保证排版准确；“文字本身改色”作为后续增强。标记不能只靠颜色，还应有下划线、角标和键盘焦点。

界面采用简洁浅色风格；卡片标题、正文、来源和控件保持稳定层级。正文对比度目标达到 4.5:1，控件和焦点边界清晰可辨。发布页不展示开发配置、密钥或调试信息。

## 8 保存分享和可移植导出

### 8.1 草稿与发布版本

本地草稿用 IndexedDB 保存 PDF、注释与媒体引用；同步云端后使用项目 revision 做乐观并发控制，冲突返回 409 并提示处理，不能静默覆盖另一标签页的修改。保存防抖 1 秒，编辑器显示保存中、已保存和保存失败。

发布生成独立、不可变的阅读快照。修改草稿不改变 HR 正在看的内容；再次发布时把分享地址指向新快照。分享 token 至少包含 128 bit 随机性，不含姓名、邮箱或顺序 ID。

阅读路由不套作者登录中间件，不要求 OpenAI、GitHub 或产品账户。作者发布前看到真实效果，并确认“持链接者可以查看及转发”。默认不被搜索引擎索引；noindex 不能被当作访问控制。

### 8.2 文件与素材访问

草稿资源存储在私有桶。公开阅读仅能访问指定发布版本引用的资源，不能通过修改文件 ID 读取他人草稿。访问资源时校验分享 token、发布状态及资源归属，不能返回任意对象路径。

撤回后公开清单立即不可用，新资源请求在 60 秒内停止；已被他人下载或截图的内容无法远程收回。删除项目同时处理资源引用，避免删掉仍被其他快照使用的文件。

### 8.3 导出形式

| 形式 | 包含内容 | 使用方式与限制 |
| --- | --- | --- |
| 公开链接 | 阅读快照、卡片与全部可用媒体 | HR 免登录；需真实 HTTPS 部署与网络测试 |
| 单文件 HTML | 页面图像、标记、卡片、所选资源及独立脚本 | 在支持本地 HTML 的浏览器中打开；聊天软件可能限制直接打开 |
| 离线 ZIP | HTML、页面图片、媒体、manifest | 解压后从浏览器打开入口，不依赖开发服务器 |
| 可编辑项目 ZIP | 原 PDF、注释 JSON、媒体、schemaVersion | 可导回编辑器继续修改 |

导出与公开页共用同一套卡片行为规则。离线 HTML 不在运行时通过 file:// 启动 PDF.js worker，而是在导出阶段把 PDF 页面转为高清图片，将热点转换为该固定页面方向的相对矩形，再嵌入数据和独立脚本。[S1]

单文件资源实际编码后超过 25 MB 时，提供 ZIP 或联网媒体选项，不能默默丢弃视频。离线导出不包含 API 密钥、账户 cookie、AI 后台接口或私有编辑记录，也不发起 AI 请求。发布后的页面图片和离线文件以保留版面为主，正文可选中与全文搜索暂不作为首版承诺；原 PDF 下载由作者另行开启。

## 9 建议技术架构

### 9.1 开发路线

采用 TypeScript 全栈：Next.js App Router 与服务端 API、React、PDF.js、Floating UI、Zod；本地草稿使用 IndexedDB。数据库选 PostgreSQL，文件使用 S3 兼容存储；自部署开发环境提供 PostgreSQL 与 MinIO。认证优先使用 Better Auth 的成熟邮箱密码能力，邮件验证与找回流程按其官方接口接入，不自行编写密码和会话算法。[S5]

模型、联网搜索和图片搜索分别封装 Provider 接口。首版搜索可接 Tavily；模型支持部署者配置的 HTTP 模型服务，至少接通一个真实提供方。访问密钥只放服务端环境变量，浏览器不能传入任意 API 基础地址让后端代为请求。

依赖版本在开发时按官方兼容说明确定并写入锁文件，README 写清运行时与安装命令。不要把某个长期变化的最新版本号写死在本 PRD 中。

### 9.2 两种渲染路径

编辑器使用 PDF.js 的 Canvas、文字层和热点层；公开快照和离线导出使用预渲染页面图片及锚点映射，避免让阅读者执行源 PDF 的脚本。页面图片应按需加载，保证热点到位后才启用交互，避免标记漂浮。

PDF 原始内容只作资料，不执行其中的 JavaScript、自动打开外部链接或启动动作。浏览器端解析不等于文件绝对安全，需使用受维护版本、限制资源消耗并做异常处理。

### 9.3 数据结构

Project：id、ownerId、title、pdfAssetId、pdfHash、pageMetadata、theme、revision、schemaVersion、createdAt、updatedAt。

Annotation：id、projectId、anchor、card、status、createdAt、updatedAt。anchor 包含 pageNumber、rectsInPdf、textQuote、prefix、suffix、sourceKind。card 包含 templateId、accentColor、title、blocks、coverAssetId、sources、imageAutoplay。

Asset：id、ownerId、projectId、kind、objectKey、mime、size、width、height、duration、sourceUrl、credit、licenseStatus。

Publication：id、projectId、token、snapshotVersion、manifestAssetId、publishedAt、revokedAt。只发布已确认注释，发布快照不能直接读取可变草稿。

AiJob：id、ownerId、annotationId、type、status、provider、usage、errorCode。AI 草稿来源单独保留，日志不记录密钥、完整 PDF 和不必要的个人信息。

### 9.4 最小 API 契约

| 接口 | 权限与用途 | 重要返回或错误 |
| --- | --- | --- |
| POST /api/projects | 作者登录后建立云端项目 | projectId 与 revision |
| PATCH /api/projects/:id | 仅作者；保存草稿与 revision | 新 revision 或 409 |
| POST /api/assets/presign | 仅作者；校验项目与配额 | 限时上传信息 |
| POST /api/assets/complete | 仅作者；确认真实文件 | 已校验 assetId |
| POST /api/ai/annotate | 仅作者；搜索与生成简介 | 草稿及真实 citations |
| POST /api/ai/images | 仅作者；查找配图 | 候选图片与来源元数据 |
| POST /api/projects/:id/publish | 仅作者；固化快照 | 免登录阅读 URL |
| DELETE /api/projects/:id/publication | 仅作者；撤回 | 撤回状态 |
| GET /r/:token | 公开；阅读页面 | 无登录拦截或编辑数据 |
| GET /api/public/:token/manifest | 公开；仅已发布清单 | 快照或 404 |
| GET /api/public/:token/assets/:id | 公开；仅该快照资源 | 文件或 404 |

服务端从会话取得 ownerId，不相信客户端声明。统一错误形状为 code、message、requestId，覆盖 AUTH_REQUIRED、FORBIDDEN、PDF_INVALID、UPLOAD_LIMIT、AI_UNCONFIGURED、SEARCH_EMPTY、RATE_LIMITED、REVISION_CONFLICT 等情况。

## 10 发布质量与安全

用户输入与生成内容以安全文本或白名单内容块渲染，不支持直接执行任意 HTML。导出内嵌 JSON 正确转义小于号和脚本结束序列。测试包含恶意链接、脚本片段和带指令的搜索结果，防止存储型脚本注入及提示词注入扩大权限。

资源导入服务只允许受控 HTTP/HTTPS 目标，限制响应大小、超时与重定向；阻止 localhost、私网、云元数据地址及重定向后的内网目标，避免后端成为内网代理。下载图片前验证实际类型。上传、搜索和模型调用均有速率及额度限制。

公共实例在上线前配置 HTTPS、会话安全、允许的来源、账户验证或注册限制、存储配额和清理任务。AI 无配置不应影响手工编辑和浏览。演示样本必须使用虚构信息；仓库不提交真实简历、个人照片、访问令牌和 .env。

## 11 验收标准

### 11.1 核心操作验收

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| AC01 | 上传真实两页 PDF | 可阅读、可选择文字，原版面不重排 |
| AC02 | 选择单词及同名词 | 仅创建所选那一处热点 |
| AC03 | 选择多行或多栏文字 | 多矩形贴合文字，不误盖另一栏 |
| AC04 | 框选 LOGO 和扫描文字 | 可调位置和大小，支持手动关键词 |
| AC05 | 缩放旋转与窗口变化 | 所列倍率、DPR、角度下误差目标 ≤2 CSS px |
| AC06 | 悬停并斜向移入卡片 | 无闪退；能点图、滚动、点击链接 |
| AC07 | 移出后关闭和重入 | 250 ms 延迟正确，重入取消关闭 |
| AC08 | 连续切换热点 | 只显示一框，无残留计时器与后台音频 |
| AC09 | 三张照片轮播 | 手动前后、可选自动、暂停与重开复位正常 |
| AC10 | 视频与全屏 | 能播放和暂停，关闭后无声，全屏不误关 |
| AC11 | 三个模板与主题色 | 外框统一，长内容内部滚动，背景文字可读 |
| AC12 | 真实 AI 搜索 | 至少一个提供方接通，有有效来源和人工采纳 |
| AC13 | AI 失败或未配置 | 不伪造内容，手工草稿保留，可继续编辑 |
| AC14 | 配图搜索与资源导入 | 候选可用、来源保留、失败可替换为上传 |
| AC15 | 保存恢复及并发 | 刷新恢复；保存错误和 409 不假报成功 |
| AC16 | 发布与匿名阅读 | 新无痕环境无任何账户，仍能读简历和媒体 |
| AC17 | 作者隔离与撤回 | 不能读改他人草稿，撤回满足新请求时限 |
| AC18 | HTML 和 ZIP 导出 | 从磁盘打开，图片与交互不依赖开发服务 |
| AC19 | 恶意内容与导出数据 | 脚本不执行、密钥不泄露、资源越权被拒 |
| AC20 | 手机及微信 | 点击展开、内部滚动、外部关闭；在真实微信中记录测试结果 |

### 11.2 性能与兼容目标

基准样本为两页 PDF 不超过 5 MB，20 个热点，每卡片三张压缩图片；测试记录机器、浏览器、网络和构建方式。桌面当前主流浏览器下，文件选定至首屏可操作目标 ≤3 秒；本地已缓存卡片从进入热点至可见目标 ≤250 ms，包含 180 ms 延迟；普通编辑操作连续执行无明显卡顿。

公开页采用 HTTPS，基础样本首屏在 10 Mbps 网络下目标 ≤4 秒；后续图片懒加载。微信可访问性、登录拦截和视频解码必须用实际目标手机验证，不能把桌面浏览器模拟手机当作微信测试通过。

### 11.3 测试与交付证据

单元测试覆盖坐标正反变换、缩放旋转、状态机计时和数据校验。浏览器端到端测试必须真实移动鼠标跨过间隙，不能只触发 mouseenter 就宣称悬浮通过；覆盖切图、视频关闭、保存重载、匿名阅读和离线导出。

测试使用虚构 PDF，至少有中英文、同名词、多行文字、图片、扫描页、旋转页和 CropBox 偏移样本。输出测试报告，逐项标记通过、未通过和未测试；API 密钥缺失、微信真机缺失和浏览器限制必须如实说明。

## 12 开发阶段与开源交付

阶段 A：本地可用流程。上传、文字及区域锚点、手工卡片、媒体、三模板、颜色、预览、自动消失、IndexedDB 和项目导入导出通过基础验收。

阶段 B：真实 AI 与配图。接通搜索和一个模型提供方、引用校验、人工采纳、候选图片导入、超时与配额，保留无 AI 手工路径。

阶段 C：多人使用与公开阅读。成熟认证、作者隔离、数据库与私有存储、发布快照、匿名路由、撤回、HTML 与 ZIP 通过完整 P0 验收。

阶段 D：公开部署验证与开源整理。完成生产构建、关键浏览器和真实微信测试，准备仓库文件和部署说明。公开仓库只包含应用源码、虚构示例及合法可分发资源。

交付包括源码、锁文件、数据库迁移、.env.example、Dockerfile、compose 配置、README、部署说明、测试报告、功能对照表和已知限制。项目原创代码建议 MIT 授权；保留第三方依赖许可及 NOTICE，不能把字体、照片或第三方代码直接改称 MIT。

README 至少说明本地体验、AI 配置、云端保存、公开部署、如何确认匿名可访问、离线导出，以及数据备份和删除。当前任务仅形成需求文档；正式产品品牌、商标及域名另行确定。

## 14 术语解释

| 术语 | 通俗解释 |
| --- | --- |
| PRD | 产品需求文档，说明要做什么、怎么操作以及怎样算做成 |
| MVP | 能完整走通主要流程的第一版产品，不等于只有演示画面 |
| PDF.js | 在浏览器里读取和显示 PDF 的开源工具 |
| 锚点 | 把注释绑定到某页某一小块位置的坐标记录 |
| 文字层 | 覆盖在 PDF 画面上的可选择文字，供鼠标选中 |
| 快照 | 发布时冻结的一份内容副本，之后改草稿不会改变它 |
| IndexedDB | 浏览器内保存文件与数据的本地数据库 |
| 对象存储 | 专门保存 PDF、图片和视频等文件的服务 |
| Provider | 可替换的服务接口，换搜索或模型公司时不用重写整个产品 |
| API | 软件之间发送请求和接收结果的约定接口 |
| OCR | 把图片中的文字识别成可处理文字的技术 |
| revision | 内容版本号，用来发现两个地方同时修改造成的冲突 |
| 源文件指纹 | 根据 PDF 字节计算的标识，用来确认注释对应哪一份文件 |
| HTTPS | 对浏览器与网站之间的传输进行加密的访问方式 |
