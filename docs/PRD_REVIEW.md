# PRD 补充核对

## 范围与来源

用户在可用首版交付后提供 HoverCV_PRD.md，说明可供参考、不要影响最后交付。原文件逐字保存在 PRD.md；开发提示词原文仍在 DEVELOPMENT_PROMPT.md。文档中的“当前任务仅形成需求文档”等句子属于附件内容，不取代用户本次已授权的开发与本机测试目标。

本次归档和验收编号纠正不改变现有测试包的操作方式。以下是差异记录，不代表这些事项已完成或已经排入新的开发任务。

## 已覆盖的核心方向

PDF 原排版与独立文字层、页码/原生坐标/SHA-256 绑定、逐行热点、区域框选、独立编辑面板、三种卡片布局、媒体与链接、延迟悬停和安全通道、IndexedDB 保存、项目恢复、不可变快照、匿名阅读、作者隔离和 revision 冲突处理，均有对应实现。不同功能的测试范围见 ACCEPTANCE.md，不笼统视为全部通过。

## 需要后续完善的产品行为

- 文字/区域选区的确认与取消；区域直接拖动、控制点缩放；相邻同一行文字片段合并。
- 多项目列表、复制、项目删除与完整的资源引用清理；换底稿后保留旧注释并明确要求重新定位的版本管理。当前换 PDF 创建独立新项目，旧项目需要先导出 ZIP 备份。
- 密码 PDF 本机输入密码、加载取消与进度、长文档可见页渲染/离屏资源释放。当前不接收密码，编辑器会渲染全部页面。
- 封面背景/文字底层/遮罩设置、图片默认 contain 与可配置裁切焦点、完整的键盘媒体操作及手机焦点/返回行为。
- 符合 PRD 的主色候选确认、完整蓝/绿/紫/琥珀色板、对比度测量。当前色板为紫/绿/琥珀/粉，主色候选提取直接应用。
- AI 的 title/summary/bullets/citations/uncertainty 格式、逐条事实的来源 ID、独立图片检索 Provider 和候选缩略图、来源页/作者/许可状态。当前模型结构为 body/citations，图像来源元数据较少，且无真实密钥验证。
- PRD 建议的统一 API 错误 code/message/requestId、账户邮件验证/找回、按 IP 和作者的成本控制、统一资源配置及公开部署验证。当前路由名称与 PRD 示例不同，内部接口配套可用，不把路由改名视为功能已经补齐。
- 发布前明确确认“持链接者可查看及转发”，分享 token 的至少 128 bit 随机性要求。当前 publication ID 使用 UUIDv4（122 个随机位），未达到 PRD 字面要求，需在保留已有链接的前提下升级。

## 默认容量差异

PRD 声明这些是可配置的建议默认值。本次不为扩大容量直接提高上限，以免超出当前“整项目内嵌 JSON”的内存与接口设计；应先统一限制配置并规划独立媒体对象。

| 项目          | PRD 建议默认值  | 当前实现                                      |
| ------------- | --------------- | --------------------------------------------- |
| PDF 大小      | 20 MB           | 20 MB                                         |
| PDF 页数      | 20 页           | 编辑器 30 页，schema 上限 100 页              |
| 项目注释数    | 100             | schema 上限 500，编辑器未统一展示此限制       |
| 每卡图片/视频 | 12 张 / 3 段    | 素材合计 30 个                                |
| 视频大小      | 100 MB          | 单个图片或视频 10 MB                          |
| 项目资源      | 250 MB          | 编辑器媒体加入时 60 MB 限制，接口请求另有限制 |
| 正文          | 2000 字         | 15000 字                                      |
| AI 上下文     | 默认最多 200 字 | 最多 500 字且由用户确认                       |
| 保存防抖      | 1 秒            | 650 ms                                        |
| 缩放核对范围  | 含 200%         | 编辑器上限 180%                               |

## 尚未完成的验收样本与外部验证

现有虚构 PDF 主要为一页英文简历。需要补中英混排、两页、同名词、多栏、图片、扫描页、旋转页和 CropBox 偏移的完整浏览器样本。坐标单元测试已经覆盖非零 CropBox 与四个旋转方向，但不能替代全部浏览器图像测量。

真实 AI/Tavily 密钥、可用 MinIO/S3 网络、HTTPS 站点和微信设备均是相应实测的外部条件。性能目标尚未按 PRD 基准采集；不能将某次页面启动时间或浏览器用例耗时替代性能验收。
