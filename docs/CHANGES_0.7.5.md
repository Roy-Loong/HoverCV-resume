# v0.7.5：恢复 PDF 翻图并缩小导出体积

v0.7.4 的全尺寸卡片控件与箭头、链接控件重叠，部分阅读器会将点击交给背景。现在背景和每个按钮分别显示同一张卡片图像的对应区域，命中区域不再重叠，避免依赖阅读器对控件的排序。点击空白正文后将焦点交回触发文字，避免出现内部控件的焦点框；卡片尺寸、图片位置及 250 ms 自动关闭策略保留。

旧版把每个照片卡片视窗保存为 3 倍分辨率的无损 PNG，照片内容导致体积大幅增加。现在保留同样的像素尺寸，照片卡片比较 PNG 与 JPEG（质量 0.92）后选较小者，文字卡片使用 PNG；背景与按钮复用同一份图像，原简历正文不重新压缩。

验证包括 77 项单元测试、类型检查和网页生产构建；实际导出 PDF 的卡片像素对比；原生 PDF 阅读器中的前后翻图、重复点击、移入阅读、250 ms 退出关闭；主计时器失效与反向控件顺序的回归。完全去掉脚本的文件仅检查原生首次翻图和基础关闭，不将其算作连续翻图通过。没有 WPS 实机环境，反向顺序测试是针对命中遮挡的回归，不能称为 WPS 实测。

同一份私人完整项目本地实测：2 页、11 条标注、22 张照片，导出由 46,558,094 字节降至 10,076,557 字节（约 9.61 MiB），缩小 78.4%，说明保留。私人项目只在本地验证，不提交简历、照片或导出文件。网页显示 v0.7.5 后重新导出，文件名带 `_v0.7.5.pdf`；旧文件不会随网站升级而变化。
