# v0.7.4：网页同款卡片与 PDF 自动关闭

此前导出只共享外框尺寸，内部重新排版并将照片缩小；点击又可能进入不自动关闭的状态。本版将网页与 PDF 的卡片内容改为共用 `CardContents` 和同一份 CSS，按 3 倍分辨率生成 PDF 外观，保留模板、颜色、换行、照片比例、缩放及焦点。原 PDF 继续保留原始页面和正文。

卡片保持 360 × 420 CSS 像素，导出为 270 × 315 PDF 点。100% 缩放时尺寸一致；PDF 阅读器缩放整页时，卡片随页面缩放。长内容通过底部上下箭头继续阅读，左右箭头切换照片，不增加简历页数。卡片外观为高清图像，原简历正文仍保留原有的文字内容。

自动关闭移除了点击固定打开的分支。进入前保护文字到卡片的斜向移动路径，进入后启用卡片附近的退出区域。退出后使用两个独立的 250 ms 计时机制，重新进入时同时取消；主计时器失效时可由备用计时器收起。退出区域还带原生 Hide 动作，支持时立即关闭，不等待脚本回调。文字到卡片的过渡区域不会被当作已经离开卡片；桌面卡片和导出的 PDF 都不再显示 ×。

隐藏控件可能仍收到阅读器的鼠标事件。本版收起隐藏控件的命中区域，并保留原始坐标以便恢复；卡片同时登记为按钮图标，避免阅读器重绘控件时抹掉外观。本版按当前卡片状态处理进入和翻图，不让旧控件重置图片；自动关闭时恢复文字触发区和稳定的退出状态。新文件名带 `_v0.7.4.pdf`，文档创建器也记录版本，避免与旧导出混淆。

## 验证范围

- 77 项单元测试、类型检查和 `npm run build:web` 通过。
- 实际网页卡片与导出 PDF 外观的像素对比，平均色差小于 4/255、大色差像素比例小于 3%。
- Chromium 原生 PDF 阅读器中操作实际导出的文件：悬停、在空隙停留、移入正文、翻图、移出关闭、重新打开、点击后从卡片附近三侧退出。在阅读器自身的边缘命中容差之外，检查 250 ms 时已关闭。
- 对主计时器返回句柄却不回调、备用计时器继续工作的情况重复验证；清空全部脚本的文件仅验证基础悬停、翻图及移到页面远处关闭，不将其算作卡片附近退出的验证通过。
- 网页的桌面移入/滚动/链接、三模板、视频与轮播、图片调整/恢复/离线导出、iPhone 和 Android 尺寸的触屏模拟。
- 私人项目本地核对：2 页、11 条标注、22 张照片、44 个内容视窗；标注区域之外像素差异为 0，说明保留。私人文件和照片不提交仓库。

没有 WPS / Acrobat 实机环境，兼容性模拟不能称为 WPS 实测。完全禁用脚本或不执行表单事件的阅读器仍有限制，不能承诺所有阅读器的相同行为；iPhone 微信 PDF 预览的原位图文弹层仍未实现。生产部署需通过网站显示 v0.7.4 核对，旧 PDF 需要重新导出。
